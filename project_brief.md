# My agent: Stargazer & Cosmic Guide

One-liner: A conversational agent that helps amateur astronomers and stargazers plan observation sessions with a catalog of celestial objects, sky condition lookups, optical calculations, and custom space visuals.

Tool coverage:
- Memory: Remembers observing location (latitude/longitude & Bortle scale), telescope/gear setup (aperture, focal length, eyepieces), and saved observation log history.
- Tools: Fetches sky condition forecasts, upcoming celestial events (meteor showers, ISS passes, planetary conjunctions), and optimal target lookups.
- Catalog/UI: Catalog of observable celestial targets (Messier objects, nebulae, planets, constellations) formatted as A2UI cards and comparison tables.
- Image gen: Generates deep-space astrophotography concepts and simulated telescopic views of nebulae, galaxies, and star clusters.
- Sandbox: Computes telescope optics metrics (magnification, field of view, focal ratio, light gathering power) and sidereal time / coordinate conversions.

Recommended for every project: memory, storage, tools, image generation, A2UI
Agent-specific / stretch (pick what fits): code sandbox for optical calculations, live weather/astronomy API integration, Cloud Trace observability
